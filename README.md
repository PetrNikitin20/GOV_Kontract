# GOV_Kontract

Демонстрационный веб-интерфейс научно-исследовательского проекта Финансового университета по теме **интеллектуального прогнозирования исполнения государственных контрактов**.

Проект демонстрирует подход к оценке риска исполнения государственных контрактов с применением методов машинного обучения и интерпретируемой аналитики. В исследовательской работе использовался объединённый набор данных из ЕИС, реестра недобросовестных поставщиков и СПАРК; исследовательский набор включал 83 184 объекта по 192 признакам.

## Состав репозитория

- `index.html` — статическая веб-демонстрация;
- `assets/style.css` — оформление;
- `assets/app.js` — фильтры, метрики, реестр, карточки и аналитика;
- `source/app.py` — Streamlit-версия;
- `source/main.py` — локальный запуск;
- `requirements.txt` — Python-зависимости;
- `build_windows.bat` — восстановление окружения и сборка Windows-версии.

> Данные в публичной веб-демонстрации синтетические. Для промышленной версии предусмотрено подключение к реальным источникам/API и обученным моделям.

## Локальный запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run source/app.py
```

## Исходный локальный пакет

В исходном архиве также находились сгенерированное виртуальное окружение `venv/` и бинарная сборка `main.exe`. Они не требуются для работы репозитория: окружение восстанавливается из `requirements.txt`, а Windows-сборка — скриптом `build_windows.bat`.
